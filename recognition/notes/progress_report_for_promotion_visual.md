## 🌟 亮点

| | | 为什么重要 |
|---|---|---|
| 👀 | **只用眼睛，不读游戏内存** | 不少游戏 AI 靠读内存作弊、封号的比比皆是 |
| 🔒 | **画面完全不外传** | 你玩什么、看到什么，只有你自己知道 |
| 🤫 | **不会刷屏** | 早期出故障会连播 2655 次；现在同一条 5 秒只说一次 |
| 🗣️ | **说人话** | 报「找不到游戏窗口」，不甩英文代码堆栈 |
| ✅ | **1105 项自动检查** | 改坏了立刻发现，不会「昨天还好好的」 |

| | 状态 | 卡在哪 |

| 🚶 | **不能**「你指个地方它自己走过去」 | 代码写完、零件测过，但**还没跑通一次完整实测** |
| 🧭 | **不能**说出「你在地图上哪个位置」 | 需要玩家**手动传送一次**建立起点，代码已完成 |
| ❤️ | **不能**读血量、能量值 | 需按你的分辨率裁一张参考图（工具已做好，**等你操作一次**） |
