# Deliberately a SEPARATE set from requirements-autopilot.txt.

# Console only does UI and process management, while the engine needs
# onnxruntime / opencv. Bundling them would slow Console startup.

# (leave it empty to reuse the Console's interpreter).

                         # void the whole repo's Apache-2.0 licence.

                         # config.toml on first launch

# used by the map renderer in the pathfinding tab
